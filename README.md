# AIX Core

AI-native infrastructure for autonomous systems and decentralized coordination.

## Overview
AIX is a foundational layer designed for intelligent agents to operate, coordinate, and settle value in a decentralized environment.

## Why AIX
AI systems are becoming autonomous.
Blockchains provide trustless settlement.
AIX connects these layers into one coherent infrastructure.

## Focus
- Agent coordination
- Data and compute access
- On-chain incentives

## Status
Early-stage research and infrastructure design.
